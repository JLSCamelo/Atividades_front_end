# Julinha Doces

Página simples de apresentação para uma loja fictícia de doces, feita com HTML e classes do Tailwind CSS.

## Como abrir

Abra o arquivo `index.html` no navegador. É necessária conexão com a internet para carregar o Tailwind CSS e as fontes Fraunces e Work Sans. As imagens usadas na página ficam na pasta `assets`.

## Seções

- Menu com links para as partes da página
- Apresentação da loja
- Sobre em quatro etapas
- Galeria de doces
- Depoimento de cliente
- Rodapé
