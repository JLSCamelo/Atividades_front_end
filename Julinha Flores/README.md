# Julinha Flores

Página inicial de uma floricultura feita como exercício de Front End com HTML, CSS e Bootstrap.

## Como abrir

1. Abra o arquivo index.html em um navegador.
2. O Bootstrap é carregado pela internet. A foto e o ícone estão salvos na pasta assets.

## Componentes usados

- Navbar responsiva com links para as seções.
- Modal com opções de buquês.
- Carrossel com depoimentos.
- Accordion de perguntas frequentes.
- Footer com copyright.

As cores principais são rosa claro e verde claro.
