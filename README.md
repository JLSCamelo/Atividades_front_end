# Atividades de Desenvolvimento Web

Repositório com atividades práticas de criação de interfaces web. Cada projeto explora uma proposta visual e uma tecnologia diferente.

## Projetos

### Julinha Flores com Bootstrap

Landing page para uma floricultura fictícia, desenvolvida com Bootstrap e uma paleta em tons claros de rosa e verde. A página inclui menu de navegação, apresentação da loja, depoimentos em carrossel, perguntas frequentes em accordion e um modal para demonstração do pedido.

### Julinha Doces com Tailwind CSS

Landing page para uma loja fictícia de doces, desenvolvida com Tailwind CSS e uma paleta em rosa-claro, lilás e azul-bebê. A página usa Fraunces nos títulos e Work Sans nos textos e inclui menu, hero, seção sobre dividida em quatro etapas, galeria de doces, depoimento e footer.

### Barba Negra Livros

Landing page fictícia criada como atividade de **vibecoding**. O projeto apresenta a proposta visual da Barba Negra Livros, uma plataforma conceitual voltada a ampliar o acesso à leitura.

O site inclui:

- hero com livros flutuantes;
- catálogo demonstrativo com carrossel de obras;
- capas de livros usadas apenas como material visual da atividade;
- ações simuladas para PDF, e-PUB, leitura online e audiobook;
- formulário de sugestão de livros;
- pop-ups de confirmação para interações demonstrativas;
- footer com canais de contato fictícios.

> Barba Negra Livros é um protótipo visual fictício. Os botões de download, leitura, audiobook e contato não realizam operações reais.

## Tecnologias

- HTML5 e CSS3;
- JavaScript;
- Python com Flask no projeto Barba Negra Livros;
- Bootstrap no projeto Julinha Flores;
- Tailwind CSS no projeto Julinha Doces;
- Google Fonts: Fraunces e Work Sans no projeto Julinha Doces.

## Organização

Cada atividade deve permanecer em sua própria pasta, com seus arquivos de execução, estilos, imagens e documentação local quando necessário.

Para executar o projeto Barba Negra Livros:

```bash
cd outputs/biblioteca-ficticia
pip install -r requirements.txt
python biblioteca_ficticia.py
```

Depois, acesse `http://localhost:5000` no navegador.

## Objetivo

As atividades foram desenvolvidas para praticar estruturação de páginas, identidade visual, responsividade, componentes de interface e interação com o usuário em projetos web fictícios.
