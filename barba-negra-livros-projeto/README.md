# Barba Negra Livros

Landing page fictícia criada para atividade de vibecoding. A proposta visual apresenta uma plataforma séria e profissional voltada ao acesso à leitura, sem downloads reais nem acervo verdadeiro.

## Como executar

```bash
pip install -r requirements.txt
python biblioteca_ficticia.py
```

Acesse `http://localhost:5000`.

## Observacoes

- Aplicação em Python com Flask.
- Conteudo, capas, contato e catalogo são fictícios.
- Botoes de PDF, EPUB, leitura online, newsletter, WhatsApp e Telegram são demonstrativos.
- Os arquivos `static/img/logo.png` e `static/img/hero.png` podem ser substituídos pelas imagens finais mantendo os mesmos nomes.
